# Quick start

1. Install Cool Pills and sign in to Coolhole in a browser tab.
2. Open a supported video page and hover over the video or its card.
3. Select **CH** to add it to the room queue. If it is already there, the control changes to **UN**.
4. If the room queue is full, use **Q+** to hold the video for later.
5. Select **CP** to run Work, add the video to Q+, or schedule it, depending on your chosen CP action.

## The controls

| Control | Action |
| --- | --- |
| **CH** | Queue the detected video in Coolhole. |
| **UN** | Remove the video from the room queue. |
| **CP** | Run Work by default; this can be changed in Settings. |
| **Q+** | Open the waiting list. Drag entries to reorder them. |
| **Frc** | Force an item from Q+ into the room queue, subject to the selected settings and room behavior. |
| **Hist** | Browse previously queued items, search, pin, or re-queue them. |
| **+Link** | Paste one or more media links into Q+. |

The pill appears on detected videos when the site is enabled. You can also use keyboard shortcuts to queue the current or hovered video, open Coolhole and Work, or toggle the Q+/history panel. See [Settings and shortcuts](Settings).

## What happens when something fails?

Cool Pills reports failures with an on-page toast. If Coolhole rejects a source as unplayable, the extension may send it to Coolhost for processing and queue the finished MP4. It does not send a replacement upload when Coolhole merely has no available queue slot. See [Reddit and Coolhost recovery](Coolhost-Recovery).

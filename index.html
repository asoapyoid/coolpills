Cool Pills

A tiny CH | CP pill on any video. One click queues it to Coolhole.

⬇ Chrome / Edge / Brave ⬇ Firefox View on GitHub

What it does

  • CH queues to Coolhole (becomes UN if already queued). Over your limit? It waits in Q+ and auto-queues when a slot opens.
  • CP focuses Coolhole and hits Work. Hold for settings.
  • Searchable history with pins, drag-reorder Q+, Schedule, multi-link paste, Gold Collector.
  • Works on YouTube, Vimeo, Twitch, TikTok, Instagram, X, Reddit, Dailymotion, Kick and any HTML5 video.
  • Themes: Default, Old Steam, King Cobra, or Match Coolhole (incl. Cinema, Black Spring and Battle.net).

Install on Chrome / Edge / Brave

  1. Download the Chrome zip and unzip it.
  2. Go to chrome://extensions and enable Developer mode.
  3. Load unpacked and choose the folder.

Install on Firefox

  1. Download the Firefox zip.
  2. Open about:debugging#/runtime/this-firefox.
  3. Load Temporary Add-on and pick the zip.

Temporary add-ons reset when Firefox restarts.

Shortcuts

  • Ctrl+Shift+Q queue current video
  • Ctrl+Shift+W focus Coolhole + Work
  • Ctrl+Shift+H toggle Hist / Q+ panel
